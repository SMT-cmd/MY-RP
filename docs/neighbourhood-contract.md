# Main neighbourhood and object approach

The main map is an authored 66×42 representative neighbourhood shared across the development capitals, not a completed map of Nigeria's cities/LGAs. Six original service buildings/doors stay fixed. All previously valid 22×14 core street positions remain walkable, so this expansion requires no saved-player relocation. Three connected district columns have named landmarks. Roads, sixteen residential facades, sixteen shade trees and nine benches define the scene. Residential facades are scenery; they are not purchasable titles or permission to enter other residents' homes. Existing property and private home contracts remain authoritative.

Server movement permits one adjacent tile at a time, checks bounds, building/scenery/bench collisions, cooldown, journey status and current location lease. Moving between these districts updates the district name and retains the same zone lease. Interstate arrival still uses its existing escrow and single-lease settlement. Recovery rejects invalid street positions, unknown regions/interiors and invalid leases. Existing generic private world-position mirrors persist the expanded coordinates and activity state; no new SQL schema is needed.

A public bench requires an adjacent confirmed street position and a current lease. Sitting records a pose only, grants no currency, goods, credentials or needs improvement, and retains idempotent receipts. Moving or entering a building clears the activity. Visual poses expire without changing economic state.

Client path planning uses breadth-first search over the authoritative obstacle catalogue. Selecting a furnishing, public seat or service building chooses a reachable interaction tile and submits individual normal movement commands, followed by the normal interaction command. The server remains responsible for permissions, proximity and settlement. The accessible Places and neighbourhoods menu offers the same visits and district walks through labelled buttons.

The route checks account, credential, region, home identity/layout version and lease before each move and interaction. It cancels on blur, hidden tab, keyboard input, changed location, busy/pending actions or response loss. A retry reconciles the pending move but does not silently restart the remainder. Native keyboard and numeric furniture placement continue to work independently of graphics. Three.js renders the catalogue; Canvas provides a depth-sorted fallback and omits offscreen floor painting.

Automated evidence covers whole-map connectivity, original tile compatibility, blocked benches, no seating rewards, backup rejection/reopening, SQL mirror reopening/replay, geometry object identity and real HTTP/DOM approach/cancellation. Nationwide content, architectural multi-room homes, unique title doors, social visitor permissions, zone handoff/reconnect capacity, streamed scenery, live browser/GPU performance and final art acceptance remain build gates.
