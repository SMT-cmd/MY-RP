## Reproduction and QA

Exact returned source paths, hashes, dimensions and observations are in the neighbouring generation JSON files. `web-encodings.json` records each served file and verifies identical decoded pixels. `tools/assets/encode-web-art.py` changes only the file encoding. No franchise screenshots, player likenesses, competitor meshes or extracted game code were used. No Unity account, paid asset purchase or API-key workflow was required.
