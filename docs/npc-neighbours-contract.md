# Scheduled NPC neighbours

Implemented component, 12 October 2026. R001/R002/R007/R056/R075 remain in progress. This is part of the main game; the independent demo is unchanged.

Six authored adult NPCs inhabit each state's representative neighbourhood. Roles include a market assistant, clinic receptionist, craftsperson, gardener, retired teacher and bus attendant. Names, curated appearance and greeting temperament derive consistently from the private world seed. These are fictional residents, not real individuals, census data or the complete NPC population. All 37 regions currently share the representative street geometry; this does not provide the 774-LGA map catalogue.

Each NPC walks an adjacent, collision-free authored route and pauses at its endpoints. Server time determines positions; a browser cannot choose the NPC's position. Schedule reads create no NPC state, receipts or business events. Existing connection heartbeats still retain their normal persistence. Three.js and Canvas use the existing adult rig/poses with NPC movement interpolation; Low/data-saver keeps keyboard and touch controls. Production art and GPU/device performance remain unverified.

Nearby controls list each NPC's occupation, current routine and location. Citizens walk within two tiles and explicitly select greeting, services, work or travel. The server requires the current location lease, outdoor position, current city, topic and execution-time range. A neighbour may move before an action reaches the server. Public player presence and privacy filters remain separate; NPC records never grant another person's identity or staff authority.

Successful conversations save one private latest record per citizen/NPC pair, a lifetime count and the ordinary immutable command receipt. Greetings recognise a repeated conversation. Advice uses authored text about the existing game services. Conversation spends no money, creates no qualification, changes no household, and confers no economic or administrative permission. Replay returns the original receipt even after the NPC moves. Separate attempts have a thirty-second cooldown. These are proposed D32 content/traffic parameters, not validated production balancing.

Private history shows the citizen's six most recent NPC records without account IDs, command evidence or another citizen's history. Live schedule updates work at an unchanged event cursor. Stable DOM controls preserve keyboard focus; session revocation clears the panel. An older live frame cannot move the scene back behind its current server time.

The PostgreSQL adapter mirrors `npc.conversation` privately. SQL enforces immutable identities, one-step counters, cooldown transitions, exact command evidence and sequential receipt counts. Orphan records/commands and unsupported counters fail. Four invoker functions deny browser execution and use the existing forced-RLS tables. Hosted migration `20261012130207` maps to local `20261012124905_scheduled_neighbour_conversations.sql`; the source hash is in the hosted manifest. Rolled-back hosted negative checks preserve world revision zero and zero citizens.

Evidence: four domain/schedule/file/backup tests; an actual HTTP/WebSocket-to-JSDOM lost-response, idle-movement, focus and revocation test; and an embedded PostgreSQL commit/rollback/reopening/forgery test. The full checkpoint has 199 passing tests; final focused PostgreSQL, interface, motion and Canvas checks plus strict TypeScript pass. No native GPU, live Node-to-Supabase driver or capacity claim follows from these tests.

Remaining NPC scope includes integrated household personalities and obligations, individual service budgets, skill/interest progression, richer reciprocal social memories, authored events, interior routines, cross-NPC traffic avoidance and nationwide content acceptance. Scripted conversations and clock-derived routes do not complete R007 or the full game. Deployment and public activation remain held.
